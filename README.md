KTM RESTAURANT - NETLIFY VERSION

This is a pure HTML/CSS/JavaScript website. No Python or Flask is required.

NETLIFY:
1. Extract this ZIP.
2. Go to Netlify.
3. Choose Add new project / Deploy manually.
4. Drag the extracted folder into the deployment area.
5. Open the generated site URL.

The menu, cart, quantity controls, delete, amount and total all work in the browser.
